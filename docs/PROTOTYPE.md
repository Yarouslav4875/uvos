# PROTOTYPE.md — прототип UVOS (`uvos-dashboard`)

Статус: каркас интерфейса, этап C в процессе. Это **приложение**, не ОС:
оно демонстрирует дизайн и принципы UVOS на обычном Android без root.

## Что уже реализовано

| Файл | Что делает | Источник правды |
|---|---|---|
| `GaugeView.kt` | Стрелочный VU-метр: размах 270°, деления каждые 10%, красная зона (последние 20%), лампочка, инерция стрелки 600 мс | `DESIGN.md` §3.1 |
| `LampView.kt` | Индикаторная лампа: горит (красный) / погашена. Мигать не умеет по определению | `DESIGN.md` §3.6 |
| `MainActivity.kt` | Экран: приборы BATT (заряд 0–100%) и TEMP (20–50°C) из системного броадкаста батареи; кнопка «ЩИТОК ДОСТУПА». Ноль разрешений | `DESIGN.md` §3.14 |
| `ShieldActivity.kt` | Контрольный щиток: шапка-прибор «ACCESS» (открыто каналов из 13) + список каналов с лампочками. Данные — ДЕМО | `DESIGN.md` §6 |
| `colors.xml` | Палитра UVOS | `DESIGN.md` §2.1 |
| `attrs.xml` | Кастомные атрибуты прибора (title, minLabel, maxLabel) | — |

## Демо-режим щитка (честная маркировка)

- Каналы фиктивные, состояние живёт только в памяти экрана.
- Переключение мгновенное; в реальной UVOS отзыв открытого канала
  требует диалога подтверждения (см. `CONTROL-SCHEME.md` §3b).
- На экране есть плашка «ДЕМО» — прототип не притворяется системой.

## Как открыть проект (после установки Android Studio)

1. Android Studio → **Open** → выбрать папку `uvos-dashboard`
   (не папку проекта целиком, а именно её).
2. При первом открытии студия скачает Gradle 8.9 и соберёт проект.
   Если предложит «обновить/создать Gradle wrapper» — соглашаться.
3. Запуск: зелёный ▶ при выбранном эмуляторе или телефоне.

## Технические решения (почему так)

- **Ноль зависимостей**: только Kotlin stdlib. Быстрая первая сборка на
  медленном канале; меньше внешнего кода — меньше рисков.
- **minSdk 26 (Android 8), targetSdk 35**: покрывает практически все
  современные устройства без усложнения кода.
- **Никаких библиотек интерфейса**: приборы рисуются на Canvas вручную —
  это и есть суть стиля UVOS, библиотеки тут не помогут.
- **`android.useAndroidX=false`**: пока нет зависимостей, androidx не нужен.

## Ограничения прототипа (не путать с возможностями ОС)

- Не ограничивает другие приложения — в обычном Android это требует
  правок уровня системы (см. `LIMITERS.md` §2, §8).
- Не читает ничего сверх броадкаста батареи.
- Не собирает и не отправляет данные нигде — сеть не используется вовсе.
