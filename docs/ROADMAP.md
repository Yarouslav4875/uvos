# ROADMAP.md — дорожная карта проекта UVOS

Статус на 27.10.2026. Проектное время: «проектируется», не «работает».

## Этап A — среда разработки ✅ ЗАВЕРШЁН

- WSL2/Ubuntu 24.04, git, python3, curl — установлены и проверены.
- Инцидент с повреждённым VHDX устранён (см. `ENVIRONMENT.md`).
- Зафиксировано честно: ресурсы ПК (≤20 ГБ ОЗУ, ~164 ГБ диска) НЕ
  позволяют полную сборку AOSP (~400 ГБ / 64 ГБ по официальным
  требованиям AOSP).
- **Критерий завершения** (выполнен): среда работает и задокументирована.

## Этап B — исследование основ 🔄 ОСНОВНОЕ ГОТОВО

- Найдена основа: LineageOS-совместимый проект для sapphire/sapphiren
  (device/vendor/prebuilt-kernel деревья, ветка lineage-22.2), активен.
- Официальной LineageOS-поддержки устройства нет (404 в вики) — основа
  сторонняя, это учтено в рисках.
- Ядро: Linux 5.15, исходники в открытом доступе (соответствие prebuilt —
  требует проверки).
- Остаточные пункты: соответствие ядра, статус сборок автора,Infinity-X
  (см. `COMPATIBILITY_NOTES.md`).
- **Критерий завершения**: выбранная основа + её репозитории описаны с
  версиями и рисками; 3 оставшихся «требует проверки» закрыты или
  осознанно приняты.

## Этап C — собственные изменения (прототип) 🔄 В ПРОЦЕССЕ

Готово: каркас `uvos-dashboard` (GaugeView, LampView, приборы батареи,
демо-щиток) — см. `docs/PROTOTYPE.md`.
План: регулятор сети, журнал, профили, диалоги подтверждения.
- **Критерий завершения**: прототип собран и проверен в эмуляторе;
  интерфейс соответствует `DESIGN.md`; всё опубликовано в Git.

## Этап D — сборочная среда ⏳ ПЛАН

- Требования сборки выбранной основы (LineageOS 22.2 / sapphire):
  оценить размер исходников и памяти. Полная сборка на текущем ПК
  невозможна.
- Варианты (обсуждать с пользователем ДО любых трат): отдельная
  Linux-машина, дополнительный диск+ОЗУ, удалённая сборочная машина.
- **Критерий завершения**: выбрано место сборки с реальными ресурсами;
  сборка AOSP для sapphire запускается и завершается без прошивки.

## Этап E — тестирование ⏳ ПЛАН

- Сначала: сборка в эмуляторе/на сборочной машине, затем проверка образа.
- Обязательны: контрольные суммы и происхождение образов; чек-лист
  функций (см. `docs/TEST-CHECKLIST.md`): загрузка, Wi-Fi, мобильная
  сеть, звонки, камера, звук, **NFC (вариант устройства — NFC!)**,
  датчики, шифрование, обновления.
- **Критерий завершения**: чек-лист пройден на реальном устройстве
  (отдельное решение владельца).

## Этап F — установка на телефон ⏳ НЕ НАЧАТ И НЕ ЗАПЛАНИРОВАН ПО ДАТЕ

- Отдельное явное согласие владельца; проверка точной модели;
  напоминание: разблокировка загрузчика Xiaomi стирает данные и имеет
  ограничения по аккаунту/региону; план восстановления и backup.
- **Критерий завершения**: не определён до начала этапа.

## Правила движения по карте

1. Этапы независимы: прототип (C) не ждёт сборку (D).
2. Ни один этап не меняет телефон без отдельного решения владельца.
3. «Требует проверки» в документах — вход в следующий этап только
   после их закрытия или осознанного принятия.
