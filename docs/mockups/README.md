# Галерея UI-макетов экосистемы UVOS (M4200 Design Language)

В данной директории содержатся официальные визуальные макеты интерфейсов операционной системы UnderVoltOS, выполненные в ретро-индустриальном приборном стиле **M4200 Retro-Industrial Instrument**:

1. [**`m4200_camera_viewfinder.png`**](m4200_camera_viewfinder.png)
   - **Приложение:** UVOS Camera (`com.uvos.camera`) — «Оптический визор».
   - **Особенности:** Миллиметровая сетка осциллографа, перекрестие, авиагоризонт, контрольная лампа `EXIF PURGE: ON`, массивная кнопка затвора с красным сердечником, статус `CH-04 // ZERO AUDIO`.

2. [**`m4200_dialer_mockup.png`**](m4200_dialer_mockup.png)
   - **Приложение:** UVOS Dialer (`com.uvos.dialer`) — «Коммутатор связи».
   - **Особенности:** Бирюзовый VFD-дисплей со строкой `ENCRYPTED CHANNEL // CH-01`, аппаратный селектор линий `TRUNK A / B` с янтарными LED, 12 механических клавиш, зеленая кнопка вызова `TRANSMIT`.

3. [**`m4200_calculator_mockup.png`**](m4200_calculator_mockup.png)
   - **Приложение:** UVOS Calculator (`com.uvos.calc`) — «Инженерный вычислитель M4200».
   - **Особенности:** Лампы тлеющего разряда (Nixie Tubes) теплого оранжевого свечения, переключатель систем счисления `[HEX] [DEC] [OCT] [BIN]`, матрица научных клавиш с металлическими окантовками.

4. [**`m4200_keyboard_mockup.png`**](m4200_keyboard_mockup.png)
   - **Приложение:** UVOS Keyboard (`com.uvos.keyboard`) — «Тактильная клавиатура M4200».
   - **Особенности:** Скульптурные клавиши с глубокими тенями, моноширинный шрифт JetBrains Mono, янтарные `SHIFT`/`DEL`, акцентный красный `ENTER`, светодиод в клавише `CAPS LOCK`, рифленый пробел.

5. [**`m4200_contacts_mockup.png`**](m4200_contacts_mockup.png)
   - **Приложение:** UVOS Contacts (`com.uvos.contacts`) — «Локальная картотека M4200».
   - **Особенности:** Картотечный реестр с аппаратным шифрованием SQLCipher, статус `AIR-GAPPED VAULT`, механический алфавитный бегунок A-Z справа, рифленая кнопка `+ RECORD`.

---
*Все макеты строго следуют инварианту: отсутствие диктофонов, микрофонов и скрытых каналов передачи телеметрии.*
