# UnderVoltOS — Интерактивные презентации интерфейса и концепта

В данном каталоге собраны дизайн-материалы, постеры и автономные интерактивные HTML-презентации пользовательского интерфейса UnderVoltOS (UVOS).

## Содержание

1. **[Интерактивная презентация всех 4 рабочих столов](uvos_ui_presentation.html)** (`uvos_ui_presentation.html`):
   - **Стол 01 (Щит / Dashboard)**: Сетка 2×2 вольтметров М4200 (CPU, MEM, BATT, NET), переключатель профилей («СТЕРИЛЬНО» / «СВЯЗЬ» / «СВОЙ»), суточный журнал блокировок.
   - **Стол 02 (Дом / Home)**: Часы UnderVoltOS, сбалансированная сетка 4×4 с системными ретро-иконками и подлинными значками нативных приложений, бронированный нижний док.
   - **Стол 03 (Меню / App Drawer)**: Закрытая территория с поиском и бейджами изоляции (`СИСТЕМА`, `ИЗОЛИРОВАНО (0)`, `1 КАНАЛ (СЕТЬ)`).
   - **Стол 04 (Менеджер процессов)**: Сводка ресурсов (ОЗУ, каналы, CPU), фильтры, управление службами («УСЫПИТЬ ВСЕ ФОНОВЫЕ СЛУЖБЫ»).
   - **Графический постер**: [`uvos_all_desktops_v9.png`](uvos_all_desktops_v9.png).

2. **[Интерактивный мобильный виджет аккумуляторов М4200](uvos_battery_widget.html)** (`uvos_battery_widget.html`):
   - Формат 4×1 для экрана телефона шириной ~360-388px в стиле iOS-виджета аккумуляторов, но на базе миниатюрных вольтметров М4200.
   - 4 слота: Смартфон (Host), Наушники (Buds), Часы (Watch), Внешний АКБ (Powerbank).
   - Поддерживает интерактивное переключение «Подключено / Отключено» с анимацией падения стрелки на механический ноль (-52°), уходом шкалы в глубокую тень и отключением светодиодов.
   - **Графические постеры**: [`uvos_battery_widget_presentation_v2.png`](uvos_battery_widget_presentation_v2.png), [`uvos_battery_widget_preview.png`](uvos_battery_widget_preview.png).
