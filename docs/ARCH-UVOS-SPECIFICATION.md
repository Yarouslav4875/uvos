# ArchUVOS (UnderVoltOS for Arch Linux) — Архитектурно-дизайнерская спецификация

**Версия:** 1.0 (Arch Linux Rolling Baseline)  
**Концепция:** «Приборный минимализм и бескомпромиссная закрытая территория»  
**Философия дизайна:** Ретро-приборы СССР / Hi-Fi (вольтметры М4200, стрелочные индикаторы VU, тумблеры, шлицевые винты) × минимализм iPhone / Apple (аккуратная сетка, радиусы 28px, глубокий темный монолит, плавная инерция).

---

## 1. Концепция и ключевое позиционирование

ArchUVOS переносит парадигму мобильной **UnderVoltOS** на десктопную платформу **Arch Linux**. 

В стандартном дистрибутиве Linux любое запущенное пользовательское приложение (браузер, Electron-клиент, проприетарная утилита, игра) имеет неконтролируемый доступ к сетевым сокетам, может считывать точное время `CLOCK_MONOTONIC`, сканировать список процессов `/proc`, опрашивать статус батареи `/sys/class/power_supply`, считывать Machine ID и генерировать цифровой отпечаток (fingerprinting).

**ArchUVOS решает эту проблему на системном уровне, объединяя:**
1. **«Закрытую территорию» (Zero-Trust Sandbox):** Каждое приложение изолировано на уровне ядра (eBPF, Bubblewrap, Landlock, seccomp). Ни байта в сеть и ни бита системных данных без явного щелчка тумблера на приборном щитке.
2. **Аппаратный контроль энергопотребления (UnderVolt Core):** Встроенный модуль андервольтинга процессора и видеокарты (CPU Core/SoC Offset, GPU Curve), ограничение лимитов мощности (Package Power Limit TDP) со стрелочными измерителями вольтажа, ампеража и температур.
3. **Приборный интерфейс (Instrument UI):** Рабочее окружение Wayland, стилизованное под прецизионный измерительный стенд с аналоговыми стрелочными приборами М4200, тумблерами и моноширинной типографикой.

## 2. Дизайн-система UVOS для Arch Linux

| Токен | Значение (HEX) | Роль в системе |
|---|---|---|
| `uvos-background` | `#0E0E12` | Основной фон экрана, рабочего стола, пустых зон |
| `uvos-tile` | `#1C1E26` | Панели, карточки окон, виджеты рабочего стола, меню |
| `uvos-tile-pressed`| `#242630` | Состояние нажатия плитки или кнопки |
| `uvos-dial` | `#E8E4D8` | Винтажный фон циферблатов приборов (слоновая кость) |
| `uvos-ink` | `#1A1A1A` | Чернила циферблата: шкалы, деления, цифры, стрелка |
| `uvos-red` | `#E02020` | Единственный яркий акцент: красная зона шкалы, активный тумблер, тревога |
| `uvos-lamp-dim` | `#7A1010` | Индикаторная дежурная лампа в выключенном состоянии |
| `uvos-text` | `#D8D8DC` | Основной контрастный текст интерфейса |
| `uvos-text-dim` | `#8A8A92` | Второстепенные подписи, системные метки, единицы измерения |
| `uvos-divider` | `#2A2C36` | Тонкие разделители карточек и списков |
| `uvos-screw` | `#2D2F3A` | Тёмные винты со шлицем по углам корпусов приборов |

> **Правило акцентного красного:** На одном экране или окне не должно быть более двух видимых красных элементов одновременно (например, одна сигнальная лампа и красная зона предельного вольтажа). Это сохраняет спокойствие рабочей среды.

### 2.2 Типографика
- **Цифры и шкалы приборов:** `Share Tech Mono` или `JetBrains Mono` — узкий моноширинный шрифт индустриального вида.
- **Заголовки плиток и категорий:** `Oswald` / `DIN 1451` (14sp/pt, ВЕРХНИЙ РЕГИСТР, разрядка букв +5%, `uvos-text-dim`).
- **Текст системы и окон:** `Inter` или чистый `Roboto` (14–16sp/pt).

### 2.3 Физические элементы управления

1. **Стрелочный прибор (UVOS Gauge — классическая серия М4200):**
   - **Конструкция и форма:** Матовый приборный корпус из темного графита (`#161820` / `#12141A`) со скруглением 26px и 5 шлицевыми винтами (4 по углам + 1 юстировочный снизу).
   - **Белый циферблат слоновой кости (`#E8E4D8`):** Прямоугольное окно циферблата с фиксированным соотношением сторон (320:220), полностью заполняющее ширину без боковых пустот и зазоров.
   - **Дуга со строгими радиальными насечками (Tick Arc):**
     - Единая черная дуга радиусом 145px, расположенная строго в верхней половине окна (на высоте $y = 50..118px$, без занижения).
     - Поперечные радиальные насечки (направленные внутрь дуги): крупные риски каждые 10% шкалы, промежуточные риски каждые 5%.
     - Черные чернила (`#1A1A1A`) на основной рабочей части шкалы, последние 25% — ярко-алый сектор перегрузки (`#E02020`).
   - **Черная стрелка с инерцией:** Игольчатая стрелка глубокого черного цвета (`#1A1A1A`) с центральным шарниром цвета циферблата, плавно отклоняющаяся с механической физикой (0.55 с).
   - **Центральная типографика:** Цифровое значение крупным моноширинным шрифтом по центру (30px) и обозначение канала (`VCORE`, `POWER`, `TRAFFIC`).
   - **Органы управления:** Интерактивные кнопки вынесены на отдельный нижний пульт управления, не касаясь корпуса и винтов.

2. **Индустриальный тумблер (UVOS Toggle):**
   - Габариты: 88×44px, радиус скругления 12px.
   - Состояние OFF: корпус `#1C1E26`, лампа `#7A1010`, подпись `OFF`.
   - Состояние ON: сочный щелчок, заливка `#E02020`, яркая светодиодная точка, подпись `ON`.

3. **Сетка рабочего стола:**
   - Монолитный тайлинг или плавающие карточки со скруглением 28px и контурной линией 1px `#2A2C36`.
   - Базовый отступ между плитками: 14px.

### 3.1 Подсистема «Закрытая территория» (Zero-Trust Sandbox)

Каждое приложение в ArchUVOS запускается в изолированном пространстве (UVOS Capsule):
- **Скрытие идентификаторов:** Приложения видят сгенерированный случайный `/etc/machine-id`, фиктивный Hostname и нулевой серийный номер оборудования.
- **Огрубление времени (Time Sanitizer):** Вызовы `clock_gettime` огрубляются до шага в 1 секунду или подменяются детерминированным таймером, что блокирует высокоточные сайд-ченнел атаки (Spectre/Meltdown-style profiling) и фингерпринтинг таймингов.
- **Маскирование батареи и питания:** Системные ноды `/sys/class/power_supply` закрыты маской; приложение видит статус «AC Connected 100%» без возможности измерять просадки вольтажа.
- **Файловый периметр (Landlock LSM):** Приложение видит только свою изолированную директорию в `~/.var/app/` и запрошенные через портал файлы. Доступ к `~/.ssh`, `~/.gnupg` или другим каталогам заблокирован на уровне ядра.

### 3.2 Сетевой регулятор (Per-App Network Governor)

- **Режим «Стерильно» (Airgap Mode):** Полная блокировка всех сетевых сокетов на уровне ядра (eBPF).
- **Режим «Выборочный допуск» (Selective Whitelist):**
  - Приложение не имеет доступа в сеть, пока в UVOS Shield не активирован соответствующий тумблер.
  - Контроль доменов: например, мессенджер может связываться только со своими официальными серверами, блокируя все аналитические трекеры.
- **Интерактивный индикатор трафика:** Аналоговый спидометр сетевой активности в реальном времени с инерционной стрелкой.

### 3.3 Модуль аппаратного контроля и андервольтинга (UnderVolt Core)

Так как дистрибутив называется **UnderVoltOS**, модуль управления питанием встроен в самую основу системы:
1. **CPU Voltage Offset:** Прямое управление смещением напряжения ядра CPU (mV) для процессоров Intel (через MSR 0x150) и AMD (через P-State / Curve Optimizer / Ryzen SMU).
2. **GPU P-State & Voltage Tuning:** Интеграция с драйверами AMDGPU / NVIDIA для ограничения TDP и фиксации энергоэффективных частот.
3. **Hardware Gauges (Аналоговые индикаторы М4200):**
   - **Vcore Вольтметр:** Текущее напряжение процессора (например, от 0.700V до 1.350V) с выделенной красной зоной выше 1.250V.
   - **Power Ваттметр:** Мгновенное энергопотребление CPU Package Power (0–65W или 0–120W).
   - **Thermal Пирометр:** Температура ядер CPU и GPU (°C).
   - **Tachometer:** Скорость вращения вентиляторов охлаждения (RPM).

### 3.4 Профили работы системы (One-Click Profiles)

1. **АВТО / Адаптивный регулятор (Default / Режим по умолчанию):**
   - Управляется системным фоновым демоном `uvos-adaptive-gov`.
   - **Не требует ручного вмешательства пользователя.** Система автоматически опрашивает кремниевую стабильность, нагрузку, частоты и температуру.
   - В простое и офисных задачах выставляет динамический андервольт до -80mV (чип холодный, вентиляторы 0 RPM), при высоких нагрузках стабилизирует смещение на уровне -50mV.
   - Ручные ползунки по умолчанию заблокированы предохранительным замком, исключая случайные сбои.
2. **Стерильно (Airgap / Cold Mode):** Сеть отключена полностью, микрофон и веб-камера аппаратно заглушены, журналы аудита активны, лимит TDP 10W.
3. **Автономия (UnderVolt Eco):** Агрессивный фиксированный андервольтинг (-80mV CPU, -50mV GPU), ограничение TDP до 18W, частота обновления экрана 60Hz. Идеально для максимальной автономности ноутбука.
4. **Рабочий (Balanced):** Стабильный андервольтинг (-50mV), включены разрешенные приложения (браузер, IDE, связь), TDP 35W.
5. **Овердрайв (Overdrive / Studio):** Полные лимиты мощности, отключение энергосбережения для рендеринга и компиляции.

## 4. Стек реализации на Arch Linux

- **Базовый дистрибутив:** Чистый Arch Linux (Linux Kernel Zen / Hardened с поддержкой Landlock, eBPF, MSR).
- **Оконный композитор:** Кастомизированный `Hyprland` или `Sway` с патчем для плавных скруглений 28px и нативным рендерингом рамок UVOS.
- **Оболочка (Shell & Dashboard):** Разработана на `Aylur's GTK Shell (AGS)` / GTK4 / Rust с аппаратным рендерингом через Cairo/Vulkan.
- **Виджеты приборов:** Векторный рендеринг SVG + CSS-трансформации стрелок с полиномиальной кривой затухания `cubic-bezier(0.18, 0.89, 0.32, 1.05)`.
- **Пакетный менеджер:** `pacman` с хуком `uvos-sandbox-gen`, автоматически создающим профиль песочницы для каждой устанавливаемой программы.
