# План тестирования UVOS (этап E): чек-листы проверок

Проект: UVOS — прошивка для Xiaomi Redmi Note 13 4G NFC (23124RA7EO, sapphire/sapphiren).
База: LineageOS lineage-22.2, ядро 5.15, SoC Snapdragon 685 (SM6225).
Статус документа: проектный. Сборок ещё не было; все пункты считаются «НЕ ПРОВЕРЯЛОСЬ».
Устройство пользователя — вариант с NFC, поэтому блок NFC обязателен.

---

## 1. Как пользоваться чек-листом

Каждый пункт получает один из трёх статусов:

- **ПРОЙДЕНО** — проверка выполнена, результат соответствует ожиданию.
- **НЕ ПРОЙДЕНО** — проверка выполнена, результат не соответствует; указать причину.
- **НЕ ПРОВЕРЯЛОСЬ** — проверка ещё не выполнялась. Это статус всех пунктов до начала работ.

Правила ведения:

1. На каждый пункт фиксируются: дата проверки и точное имя сборки (версия, дата, хэш образа).
2. Ни один пункт не считается пройденным «по умолчанию». Отсутствие записи = «НЕ ПРОВЕРЯЛОСЬ».
3. Статус ставится только по факту наблюдаемого результата, а не по ожиданиям из проекта.
4. Повторная проверка после правок прошивки: предыдущий статус аннулируется, пункт закрывается заново.
5. Замечания с пометкой «блокирующее» останавливают переход к следующему этапу до устранения.

Формат записи (пример, без личных данных):

```
Пункт: 3.2 Wi-Fi спящий режим
Сборка: uvos-sapphire-testbuild (дата: __)
Дата: __
Статус: ПРОЙДЕНО / НЕ ПРОЙДЕНО / НЕ ПРОВЕРЯЛОСЬ
Примечание: __
```

## 2. Проверка происхождения образа (ДО запуска)

- [ ] Вычислен SHA-256 образа; значение совпадает с опубликованным в официальном канале проекта.
- [ ] Проверены контрольные суммы всех вспомогательных образов, если они входят в комплект.
- [ ] Проверена подпись сборки (если механизм подписи предусмотрен) — подпись валидна.
- [ ] Источник образа — официальный канал проекта; совпадение имени версии и даты.
- [ ] Сборка помечена как тестовая; пользователь предупреждён о рисках установки сторонних прошивок.

**Предупреждение:** образ, полученный из непроверенного источника (пересылка, сторонний сайт,
файл без совпадающего SHA-256), не тестируется. Сначала — выяснение происхождения, затем повторная
проверка сумм. Тестирование непроверенного образа запрещено.

## 3. Базовая загрузка

- [ ] Первая загрузка завершается до домашнего экрана без зависаний.
- [ ] Время первой загрузки зафиксировано (ожидается дольше обычной из-за первичной инициализации).
- [ ] Логотип отображается корректно, без артефактов.
- [ ] Первичная настройка (язык, Wi-Fi, пропуск аккаунтов) проходит без сбоев.
- [ ] Перезагрузка x3 подряд — каждая завершается успешно, время загрузки стабильное.
- [ ] Аварийная перезагрузка (принудительная перезагрузка устройства) — система возвращается в рабочее состояние.
- [ ] После аварийной перезагрузки пользовательские данные сохранены.

## 4. Связь

### 4.1 Wi-Fi
- [ ] Подключение к сети с паролем — успешно, индикация корректна.
- [ ] Подключение к открытой сети — успешно.
- [ ] Диапазон 2,4 ГГц — видится и работает.
- [ ] Диапазон 5 ГГц — видится и работает (если точка доступа поддерживает).
- [ ] Спящий режим: после пробуждения Wi-Fi восстанавливается сам.
- [ ] Потеря связи и возврат точки доступа — переподключение без ручного вмешательства.

### 4.2 Мобильная сеть
- [ ] SIM 1: сеть регистрируется, тип сети отображается.
- [ ] SIM 2: сеть регистрируется, тип сети отображается.
- [ ] Две SIM одновременно: обе активны, переключение данных между ними работает.
- [ ] Мобильные данные: включение/отключение, передача данных фактически идёт.
- [ ] Ручной выбор сети и выбор «только 4G/3G/2G» применяется.

### 4.3 Звонки и СМС
- [ ] Исходящий звонок: соединение, двусторонняя слышимость.
- [ ] Входящий звонок: звонок слышен, ответ работает, завершение корректно.
- [ ] СМС исходящее и входящее — доставка и отображение.
- [ ] Во время разговора сеть не отваливается; после звонка данные восстанавливаются.

### 4.4 GPS
- [ ] Местоположение определяется (по открытом небу), точность приемлемая.
- [ ] Приложения, запрашивающие геолокацию, получают координаты.

## 5. Мультимедиа и железо

### 5.1 Камера
- [ ] Основной модуль 108 МП: съёмка фото, просмотр, файл не повреждён.
- [ ] Ультраширик 8 МП: съёмка, изображение заметно шире основного.
- [ ] Макро 2 МП: съёмка с близкого расстояния.
- [ ] Фронтальная 16 МП: съёмка, переключение между камерами без сбоев.
- [ ] Запись видео (хотя бы основная камера): запись, воспроизведение, звук в видео есть.

### 5.2 Звук
- [ ] Динамик: звонок, музыка, системные звуки — слышимы, без искажений.
- [ ] Микрофон: запись голосового сообщения, воспроизведение разборчиво.
- [ ] Наушники (проводные через переходник или Bluetooth): звук идёт в наушники, микрофон работает.

### 5.3 Вибрация
- [ ] Вибрация на входящем звонке, уведомлении, в настройках — срабатывает.

### 5.4 ИК-порт
- [ ] ИК-порт виден в приложении пульта, тестовая команда на ИК-устройство отправляется
      (проверка по реакции устройства-приёмника, если доступно).

### 5.5 Дисплей
- [ ] AMOLED: чёрный цвет действительно чёрный (нет подсветки на тёмном фоне).
- [ ] Частота 120 Гц: плавность прокрутки заметна; в настройках частота применяется.
- [ ] Яркость: минимальная и максимальная, автояркость реагирует на датчик света.
- [ ] Always-On Display (если включён) — отображается и не расходует аномально батарею.

### 5.6 Отпечаток (UDFPS)
- [ ] Регистрация отпечатка в экране проходит до конца.
- [ ] Разблокировка экрана отпечатком — срабатывает reliably (не менее 8 из 10 попыток).
- [ ] Разблокировка работает и при включённом Always-On Display.

## 6. NFC — обязательный блок

> Для варианта устройства с NFC провал **любого** пункта этого блока — **блокирующее замечание**.

- [ ] NFC включается и выключается в настройках; состояние отображается.
- [ ] Чтение метки: NFC-метка считывается приложением, данные метки отображаются.
- [ ] HCE (эмуляция карты): приложение-эмулятор отвечает на запрос терминала/ридера.
- [ ] Обмен между устройствами (Android Beam-подобный сценарий / peer-to-peer, если поддерживается):
      передача данных между двумя NFC-устройствами завершается успешно.
- [ ] Состояние после перезагрузки: настройка NFC (вкл/выкл) и зарегистрированные HCE-приложения
      сохраняются, HCE работает после рестарта без переустановки.

## 8. Специфика UVOS

### 8.1 Контрольный щиток
- [ ] 13 каналов по умолчанию находятся в состоянии «ЗАКРЫТО» после первой загрузки.
- [ ] Открытие канала требует подтверждения; случайное открытие исключено.
- [ ] Отзыв (закрытие) канала применяется **мгновенно** — без ожидания перезагрузки.
- [ ] Отзыв канала требует подтверждения — подтверждение запрашивается.
- [ ] Приложение, активность которого была отозвана, фактически теряет доступ сразу
      (проверить наблюдаемым эффектом, а не только индикацией в интерфейсе).

### 8.2 Регулятор сети
- [ ] Режим «Закрыто»: вся сеть блокируется — проверяется фактическим отсутствием трафика.
- [ ] Режим «Белый список»: проходит только разрешённое; неразрешённое не получает доступа.
- [ ] Режим «Открыто»: доступ есть у всех, как в базовом состоянии.
- [ ] Лимит (если задан лимит на канал): при исчерпании соединение обрывается.
- [ ] Переключение режимов применяется мгновенно, без перезагрузки.

### 8.3 Журнал попыток
- [ ] Заблокированная попытка доступа попадает в журнал (время, канал, результат).
- [ ] Журнал не теряет записи после закрытия и повторного открытия приложения.
- [ ] Журнал можно просмотреть и очистить; очистка работает.

### 8.4 Профили ограничений
- [ ] Профиль «Стерильно» применяется мгновенно; состояние щитка меняется предсказуемо.
- [ ] Профиль «Связь» применяется мгновенно; канал связи открывается по правилам профиля.
- [ ] Переключение «Стерильно» ↔ «Связь» туда-обратно — оба состояния корректны.

### 8.5 Переживание перезагрузки
> После **каждого** изменения в этом разделе — перезагрузка и повторная проверка.
- [ ] Состояния всех 13 каналов сохраняются после перезагрузки.
- [ ] Режим регулятора сети сохраняется; правила фильтрации работают сразу после рестарта.
- [ ] Белый список сохраняется и применяется после рестарта.
- [ ] Активный профиль сохраняется и применяется после рестарта.
- [ ] Лимиты сохраняются после рестарта.
- [ ] Записи журнала попыток сохраняются после рестарта.

> Этот раздел требует реальной сборки и реального устройства; до сборки — не проверяется.

- [ ] Шифрование пользовательских данных включено по умолчанию (статус шифрования отображается).
- [ ] После шифрования/первой загрузки с шифрованием данные доступны, сбоев нет.
- [ ] Обновление OTA: процедура обновления запускается и завершается без потери данных
      (на тестовой сборке).
- [ ] После OTA-обновления права щитка (открытые/закрытые каналы) сохраняются.
- [ ] После OTA-обновления режим регулятора сети и белый список сохраняются.
- [ ] После OTA-обновления журнал попыток не стирается.

## 10. Критерии завершения этапа E

Этап E считается завершённым, когда:

1. Все пункты со статусом «НЕ ПРОВЕРЯЛОСЬ» переведены в «ПРОЙДЕНО» или «НЕ ПРОЙДЕНО»
   с записью даты и сборки; открытых «НЕ ПРОВЕРЯЛОСЬ» не осталось.
2. Все «НЕ ПРОЙДЕНО» либо устранены и перепроверены, либо явно помечены как блокирующие/неблокирующие
   с обоснованием.
3. Блок NFC полностью пройден (для NFC-варианта устройства любой провал здесь блокирующий).
4. Раздел 8 (специфика UVOS) полностью пройден, включая проверки переживания перезагрузки.
5. Раздел 9 проверен на реальной сборке (не на проектных допущениях).

**Решение о готовности** к следующему этапу принимает владелец проекта на основании этого документа.
Тестовый документ не заменяет решение; он только фиксирует факты.
