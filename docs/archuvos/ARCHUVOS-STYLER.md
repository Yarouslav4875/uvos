# ARCHUVOS-STYLER.md — Спецификация визуального бэкграунда и генератора тем UVOS Arch Styler

**Версия:** 1.0 (Arch Linux Rolling Baseline)  
**Компонент:** `archuvos-styler` (Theming Engine & Visual Background System)  
**Концепция дизайна:** «Тёмная комната, подсвеченные ретро-приборы М4200 × iPhone-минимализм»

---

## 1. Философия и принципы стиля

Визуальный бэкграунд ArchUVOS превращает монитор компьютера в прецизионную измерительную приборную панель высокого класса:
1. **Приборный скевоморфизм без китча:** Никаких псевдо-3D бликов, глянца и пёстрых градиентов. Корпуса матовые, винты тёмные с механическим шлицем, циферблаты цвета слоновой кости (`#E8E4D8`), стрелки чернильные (`#1A1A1A`).
2. **Тёмный монолит (`#0E0E12`):** Экран воспринимается как цельная панель из анодированного алюминия или эбонита с порошковой покраской.
3. **Строгая палитра одного акцента:** Алый цвет (`#E02020`) появляется только на конце стрелки в критической зоне, в точке активного тумблера или при тревоге. На одном экране одновременно видно не более двух алых элементов.
4. **Статика вместо миганий:** Ни один индикатор в системе никогда не пульсирует и не мигает. Ситуация внимания отображается ровным непрерывным свечением дежурной лампы.
5. **Инерция механической стрелки:** Плавное движение индикаторов с кривой затухания реальной пружины `cubic-bezier(0.18, 0.89, 0.32, 1.05)` длительностью 0.55 с.

## 3. Архитектура утилиты `archuvos-styler`

`archuvos-styler` — централизованный менеджер тем и визуального оформления рабочего стола. Написан на Rust, работает как CLI-инструмент и D-Bus служба (`org.archuvos.Styler`).

```
                              ┌──────────────────────┐
                              │  /etc/archuvos/      │
                              │     theme.toml       │
                              └──────────┬───────────┘
                                         │
                              ┌──────────▼───────────┐
                              │   archuvos-styler    │
                              │   (Theme Engine)     │
                              └──────────┬───────────┘
                                         │
        ┌────────────────┬───────────────┼────────────────┬───────────────┐
        ▼                ▼               ▼                ▼               ▼
 ┌─────────────┐  ┌─────────────┐ ┌─────────────┐  ┌─────────────┐ ┌─────────────┐
 │ Обои стола  │  │   Plymouth  │ │   Greetd /  │  │  Hyprland / │ │  GTK 3/4,   │
 │ (SVG / WPE) │  │ Boot Splash │ │     SDDM    │  │ Waybar / AGS│ │ Kitty, Rofi │
 └─────────────┘  └─────────────┘ └─────────────┘  └─────────────┘ └─────────────┘
```

### 3.1 Ключевые возможности:
- **Генерация обоев «на лету» (Procedural Wallpaper Generation):** Создает векторные SVG/PNG обои под любое разрешение экрана (1080p, 2K, 4K, UltraWide) с корректным позиционированием угловых винтов и калибровочной сетки.
- **Сквозная синхронизация:** Один вызов `archuvos-styler apply` генерирует и обновляет конфиги для Hyprland, Waybar, Kitty, Alacritty, GTK 3/4, Dunst и Rofi без перезапуска сессии.
- **Экспорт тем:** Автоматически создает файлы палитры для сторонних приложений (Sublime Text, VS Code, Obsidian, Neovim).

## 4. Спецификация визуального бэкграунда (Wallpapers & Backgrounds)

### 4.1 Концепция обоев «Приборный стенд М4200»

Обои рабочего стола ArchUVOS — это не абстрактный арт, а реалистичная текстура инструментальной панели:
1. **Базовый слой:** Глубокий темный фон `#0E0E12` с легким диффузным шумом порошковой стали (opacity 3%).
2. **Прецизионная координатная сетка (Engraved Grid):**
   - Тонкие лазерные линии цвета `#171821` (толщина 1px).
   - Основная сетка с шагом 100×100px; вспомогательная миллиметровка с шагом 20×20px.
3. **Угловые металлические винты М4:**
   - 4 винта со шлицем по углам монитора с отступом 28px от границ экрана.
   - Диаметр винта: 24px. Шлицы ориентированы в естественном разнобое (0°, 45°, 90°, 135°), подчеркивая ручную сборку прибора.
4. **Индустриальная гравировка:**
   - В нижнем левом углу экрана: `ARCHUVOS INSTRUMENT PLATFORM · BASELINE REV 1.0` шрифтом `Share Tech Mono` (цвет `#3A3C48`).
   - В правом нижнем углу: калибровочная шкала миллиметровки 0–100 мм.

## 5. Оформление системных компонентов

### 5.1 Экран загрузки ядра (Plymouth Theme `archuvos-boot`)
- **Поведение:** При инициализации ядра Linux экран плавно выходит из черного цвета.
- **Центральный элемент:** Одиночный аналоговый прибор М4200 с маркировкой `SYSTEM VOLTAGE / BOOT INTEGRITY`.
- **Анимация:**
  1. Стрелка плавно отклоняется от 0% до 100%, тестируя механику.
  2. В момент монтирования корневого раздела `/` стрелка стабилизируется на номинале 12.0V.
  3. В правом верхнем углу корпуса мягко зажигается сигнальная лампа `lamp_dim` → `text_primary` (готовность).
  4. Без текстовых логов загрузки (по нажатию `Esc` открывается моноширинный лог с красным курсором).

### 5.2 Экран входа (Greetd / SDDM Theme `archuvos-greeter`)
- **Фон:** Стенд с координатной сеткой и угловыми винтами.
- **Центральная плитка (380×300px, радиус 28px):**
  - Верхняя часть: аналоговый мини-прибор «STATUS: LOCKED».
  - Поле ввода пароля: матовая впадина `#14151B`, курсор цвета `#E02020`, скрытые символы отображаются рисками на приборной линейке.
  - Кнопка разблокировки: тумблер `ARM / UNLOCK` (при правильном пароле тумблер с сочным щелчком переключается в положение `ARMED`).

### 5.3 Оконный композитор (Hyprland / Sway Theme)
- **Скругление углов окон:** Ровно 28px (`rounding = 28`).
- **Рамки окон:**
  - Неактивное окно: матовая граница 1px цвета `#2A2C36`.
  - Активное фокусное окно: деликатный контур 1.5px цвета `#E02020` без неонового свечения и размытия.
- **Отступы между окнами (Gaps):**
  - `gaps_in = 8`
  - `gaps_out = 14` (равномерный шаг, гармонирующий с панелью).
- **Анимация:**
  - Окна открываются легким увеличением (0.2s, decelerate).
  - Никаких пружинных «желейных» эффектов.

### 5.4 Статусная панель (Waybar / Aylur's GTK Shell)
- **Расположение:** Верхняя часть экрана, плавающая панель с отступом 10px от краев, скругление 20px, фон `#1C1E26`.
- **Модули:**
  1. **Индикатор процессора:** Миниатюрный вольтметр со стрелкой, отображающий напряжение Vcore и температуру ядра.
  2. **Индикатор сети:** Две точечные лампы (Rx / Tx). Выкл — `#7A1010`, передача данных — `#D8D8DC`.
  3. **Индикатор песочницы (Shield Status):** Если хоть одно приложение имеет доступ в сеть — горит алая лампа `#E02020`. Если система в режиме «Стерильно» — все лампы в дежурном темно-вишневом режиме.
  4. **Часы:** Моноширинные цифры `Share Tech Mono`, разделитель двоеточия статичен (не мигает).

### 5.5 Меню приложений (Rofi / Walker)
- Центрированная карточка 600×420px, радиус 28px, фон `#1C1E26`.
- 4 металлических винта по углам карточки.
- Каждая строка приложения снабжена индикаторным светодиодом:
  - Серый светодиод: приложение изолировано (Сеть: OFF, Доступ: Sandbox).
  - Красный светодиод: приложению явно открыт доступ в сеть владельцем.

## 6. Формат конфигурации `/etc/archuvos/theme.toml`

```toml
[theme]
name = "ArchUVOS Industrial Dark"
version = "1.0"
author = "UVOS Core Team"

[palette]
background = "#0E0E12"
tile = "#1C1E26"
tile_pressed = "#242630"
dial = "#E8E4D8"
ink = "#1A1A1A"
red = "#E02020"
lamp_dim = "#7A1010"
text = "#D8D8DC"
text_dim = "#8A8A92"
divider = "#2A2C36"
screw = "#2D2F3A"

[typography]
gauge_font = "Share Tech Mono"
title_font = "Oswald"
ui_font = "Inter"

[geometry]
window_corner_radius = 28
tile_corner_radius = 28
control_corner_radius = 12
border_width = 1
screw_margin = 10
needle_inertia_ms = 550

[wallpaper]
type = "procedural"
grid_step = 100
subgrid_step = 20
screws_enabled = true
engraving_text = "ARCHUVOS · INSTRUMENT DIVISION · NO. 23124"
```

## 7. Команды управления `archuvos-styler` CLI

```bash
# Применить текущую тему ко всем компонентам окружения
archuvos-styler apply

# Сгенерировать обои рабочего стола под текущее разрешение мониторов
archuvos-styler generate-wallpaper --output /usr/share/backgrounds/archuvos/default.svg

# Переключить цветовой профиль (например, ночной дежурный режим)
archuvos-styler set-mode night

# Проверить целостность конфигурации тем и геометрии
archuvos-styler doctor
```
