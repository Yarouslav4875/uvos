# UnderVoltOS (UVOS)

Личная исследовательская платформа для разработки Android-совместимой прошивки
UnderVoltOS для Xiaomi Redmi Note 13 4G NFC (23124RA7EO, codename sapphire/sapphiren).

## Концепция

- **Стиль**: ретро-приборы (VU-метры, вольтметры/амперметры со стрелками)
  в смеси с минимализмом iPhone. Тёмный фон, бледный циферблат, красные акценты.
- **Суть**: «закрытая территория» для приложений — по умолчанию приложение не
  получает НИКАКИХ данных об устройстве и пользователе (время, заряд,
  идентификаторы), интернет выдаётся и регулируется явно.
  Полная изоляция времени/заряда требует правок уровня ОС — см. REQUIREMENTS.md.

## Интерактивные презентации интерфейса

- **[Интерактивная презентация всех 4 мониторов (Щит, Дом, Меню, Процессы)](docs/presentations/uvos_ui_presentation.html)**:
  - Стол 01 (Щит / Dashboard): сетка вольтметров М4200 (CPU, MEM, BATT, NET), выбор профилей («СТЕРИЛЬНО» / «СВЯЗЬ» / «СВОЙ»), суточный журнал.
  - Стол 02 (Дом / Home): часы UnderVoltOS, ретро-сетка 4×4 + подлинные системные иконки нативных приложений, 4-слотовый док.
  - Стол 03 (Меню / App Drawer): закрытая территория с поиском и бейджами изоляции (`СИСТЕМА`, `ИЗОЛИРОВАНО (0)`, `1 КАНАЛ (СЕТЬ)`).
  - Стол 04 (Менеджер процессов): ресурсы в реальном времени, фильтрация процессов, кнопка «УСЫПИТЬ ВСЕ ФОНОВЫЕ СЛУЖБЫ».
  - Постер: [`docs/presentations/uvos_all_desktops_v9.png`](docs/presentations/uvos_all_desktops_v9.png).
- **[Мобильный батарейный виджет UnderVoltOS (4×1)](docs/presentations/uvos_battery_widget.html)**:
  - Горизонтальная плашка на 4 слота с вольтметрами М4200 (Host, Buds, Watch, АКБ).
  - Интерактивное подключение/отключение устройств, физическое обесточивание шкалы, падение стрелки на -52° и индикаторы.
  - Постеры: [`docs/presentations/uvos_battery_widget_presentation_v2.png`](docs/presentations/uvos_battery_widget_presentation_v2.png), [`docs/presentations/uvos_battery_widget_preview.png`](docs/presentations/uvos_battery_widget_preview.png).

## Документы проекта

- `docs/presentations/` — презентации и дизайн-материалы интерфейса UVOS.
- `ENVIRONMENT.md` — зафиксированная среда разработки (Windows 11 + WSL2/Ubuntu 24.04).
- `REQUIREMENTS.md` — требования и видение UVOS.
- `DESIGN.md` — стильгайд и дизайн-система элементов.
- `COMPATIBILITY_NOTES.md` — исследование совместимости основ прошивки для sapphire.

## Статус

- Этап A (среда): завершён.
- Этап B (исследование основ): завершён.
- Этап C (прототип UVOS): реализованы все 4 монитора интерфейса в приложении `com.uvos.dashboard`, собраны через Gradle и упакованы в образ `system.img`.
- Прошивка телефона: НЕ выполнялась и не планируется до отдельного решения.
